# Feedback & Issues

These documentation pages mirror the live [Genkō application](https://getgenko.com). If you spot a problem in the app, have a feature idea, or want to flag a docs error, the fastest way to reach the team is through GitHub Issues in this repository.

---

## How to file an issue

Go to the [Issues tab](../../issues/new/choose) and choose the template that fits your situation.

### Bug report — getgenko.com

Use this when something in the Genkō application is broken or behaving unexpectedly.

**Good examples:**
- "Clicking Save on the appointment form does nothing"
- "The patient portal shows the wrong provider name"
- "Google Calendar sync stopped working after connecting a new account"

You will be asked for: a description of what happened, what you expected, steps to reproduce, and which part of the app is affected.

### Feature request / feedback

Use this when you have a product idea or a workflow you wish Genkō handled differently.

**Good examples:**
- "I'd like automated SMS reminders before appointments"
- "It would help to filter the patient list by last visit date"
- "The analytics page doesn't show cancellation reasons"

You will be asked for: the problem you are trying to solve, what you would like to see, and any alternatives you have considered.

### Docs feedback

Use this when the documentation itself is wrong, outdated, or unclear.

**Good examples:**
- "The scheduling guide says to click 'New Booking' but the button is now labelled 'New Appointment'"
- "The MCP API section is missing the authentication step"
- "Step 3 in Getting Started no longer matches the current UI"

---

## Before opening an issue

- Check the [open issues](../../issues) to see if someone has already reported the same thing.
- For general product questions, the live docs at [getgenko.com/docs](https://getgenko.com/docs) may already have the answer.

## Security vulnerabilities

**Do not open a public issue for security vulnerabilities.** See the [Security Policy](https://github.com/search?q=repo%3Agenko+SECURITY.md&type=code) for responsible disclosure instructions.

---

{: .note }
Issues filed here are monitored by the Genkō team. While response times may vary, every report is read and considered for the product roadmap.
