# Geschäftsprofilverwaltung

Ihr Geschäftsprofil ist die öffentliche Identität Ihrer Klinik innerhalb von Genkō. Ein vollständiges Profil schafft Vertrauen bei Patienten und gewährleistet reibungslose Abläufe.

---

## Zugriff auf das Geschäftsprofil

1. Navigieren Sie zu **Geschäftsprofil** in der Seitenleiste (unter Verwaltung)
2. Oder klicken Sie auf das Profilvervollständigungs-Banner auf Ihrem Dashboard
3. URL: `/admin/business-profile`

---

## Warum Ihr Geschäftsprofil wichtig ist

Ein vollständiges Geschäftsprofil:
- **Schafft Patientenvertrauen**: Patienten sehen professionelle Informationen über Ihre Klinik
- **Aktiviert Funktionen**: Einige Funktionen erfordern Organisationsdetails
- **Verbessert Kommunikation**: Ihre Klinikinformationen erscheinen in Patientenbenachrichtigungen
- **Unterstützt öffentliche Einträge**: Ihre Klinik kann in öffentlichen Verzeichnissen erscheinen

## Geschäftsprofil-Bereiche

### 1. Organisationsinformationen

#### Grundlegende Details
| Feld | Beschreibung | Erforderlich |
|------|--------------|--------------|
| **Organisationsname** | Name Ihrer Klinik oder Praxis | Ja |
| **Rechtlicher Name** | Offiziell registrierter Geschäftsname | Nein |
| **Beschreibung** | Kurze Beschreibung Ihrer Praxis | Empfohlen |

#### Kontaktinformationen
| Feld | Beschreibung | Format |
|------|--------------|--------|
| **E-Mail** | Primäre Kontakt-E-Mail | email@beispiel.de |
| **Telefon** | Primäre Telefonnummer | +49 (30) 1234567 |
| **Website** | Website Ihrer Praxis | https://beispiel.de |

#### Adressinformationen
| Feld | Beschreibung |
|------|--------------|
| **Adresse** | Gebäudenummer und Straßenname |
| **Zusatz** | Zusätzliche Adresszeile (optional) |
| **Stadt** | Stadtname |
| **Bundesland** | Bundesland |
| **Postleitzahl** | PLZ |
| **Land** | Land (automatisch erkannt) |

### 2. Branding und Logo

#### Logo hochladen
- **Unterstützte Formate**: PNG, JPG, WEBP
- **Empfohlene Größe**: Mindestens 200x200 Pixel
- **Maximale Dateigröße**: 2MB
- **Form**: Quadratische Logos funktionieren am besten

**Um ein Logo hochzuladen:**
1. Klicken Sie auf den Logo-Upload-Bereich oder ziehen Sie Ihr Bild per Drag & Drop
2. Vorschau des Logos vor dem Speichern
3. Klicken Sie auf **Speichern**, um Änderungen anzuwenden

#### Markenfarben (Demnächst)
- Primärfarbauswahl
- Sekundärfarbauswahl
- Akzentfarbauswahl

### 4. Praxisschwerpunkte

Wählen Sie die Fachgebiete, die Ihre Praxis anbietet:
- Allgemeinmedizin
- Familienmedizin
- Pädiatrie
- Innere Medizin
- Dermatologie
- Kardiologie
- Und mehr...

**Schwerpunkte hinzufügen:**
1. Klicken Sie auf **Schwerpunkt hinzufügen**
2. Wählen Sie aus der Dropdown-Liste
3. Wiederholen Sie für weitere Schwerpunkte
4. Klicken Sie auf **Speichern**

Konfigurieren Sie akzeptierte Zahlungsmethoden und Versicherungen:

#### Akzeptierte Versicherungsanbieter
- Fügen Sie Versicherungsunternehmen hinzu, die Sie akzeptieren

- Bargeld
- Kredit-/Debitkarten

## Profilvervollständigungsanzeige

Die Profilvervollständigungsanzeige zeigt Ihren Fortschritt:

| Vervollständigung | Status | Aktion |
|-------------------|--------|--------|
| 0-25% | 🔴 Unvollständig | Pflichtfelder ausfüllen |
| 26-50% | 🟡 Grundlegend | Weitere Details hinzufügen |
| 51-75% | 🟡 Gut | Fast komplett |
| 76-99% | 🟢 Fast fertig | Letzte Details hinzufügen |
| 100% | 🟢 Vollständig | Profil vollständig eingerichtet |

**Erforderlich für 100%:**
- Organisationsname
- E-Mail-Adresse
- Telefonnummer
- Adresse
- Logo

## Änderungen speichern

Änderungen werden auf zwei Arten gespeichert:

### Automatisches Speichern
- Einige Felder speichern automatisch während der Eingabe
- Achten Sie auf die Anzeige "Speichern..."

### Manuelles Speichern
- Klicken Sie auf den **Speichern**-Button in der oberen rechten Ecke
- Warten Sie auf die Bestätigung "Erfolgreich gespeichert"

**Warnung bei ungespeicherten Änderungen:**
- Wenn Sie versuchen, mit ungespeicherten Änderungen zu navigieren, sehen Sie eine Warnung
- Wählen Sie, ob Sie Ihre Änderungen speichern oder verwerfen möchten

## Best Practices

### Logo-Richtlinien
1. Verwenden Sie ein hochauflösendes Bild für beste Qualität
2. Stellen Sie sicher, dass das Logo auch in kleinen Größen lesbar ist
3. Verwenden Sie ein einfaches, klares Design
4. Halten Sie konsistentes Branding über alle Materialien

### Beschreibungstipps
1. Halten Sie es prägnant (2-3 Sätze)
2. Erwähnen Sie Ihre Hauptschwerpunkte
3. Fügen Sie Ihr Alleinstellungsmerkmal hinzu
4. Verwenden Sie professionelle Sprache

### Kontaktinformationen
1. Verwenden Sie eine dedizierte Geschäfts-E-Mail (nicht persönlich)
2. Stellen Sie sicher, dass die Telefonnummer während der Geschäftszeiten beantwortet wird
3. Halten Sie die Website-URL aktuell
4. Überprüfen Sie, dass die Adresse für die Patientennavigation korrekt ist

## Datenschutzüberlegungen

Ihre Geschäftsprofilinformationen können sichtbar sein für:
- Ihre Mitarbeiter
- Ihre Patienten
- Öffentliche Verzeichnisse (falls aktiviert)

**Sensible Informationen:**
- Finanzielle Details werden **niemals** öffentlich angezeigt
- Persönliche Mitarbeiterinformationen sind geschützt
- Patientenzahlen sind privat

## Fehlerbehebung

### Logo wird nicht hochgeladen
- Überprüfen Sie das Dateiformat (nur PNG, JPG, WEBP)
- Reduzieren Sie die Dateigröße, wenn über 2MB
- Probieren Sie einen anderen Browser
- Browser-Cache leeren

### Änderungen werden nicht gespeichert
- Überprüfen Sie die Internetverbindung
- Suchen Sie nach Fehlermeldungen
- Aktualisieren Sie die Seite und versuchen Sie es erneut
- Kontaktieren Sie den Support, wenn das Problem weiterhin besteht

### Adressvalidierungsfehler
- Stellen Sie sicher, dass das Adressformat zu Ihrem Land passt
- Überprüfen Sie auf Tippfehler
- Versuchen Sie, die Adresskomponenten einzeln einzugeben
