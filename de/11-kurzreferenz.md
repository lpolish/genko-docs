# Schnellreferenz

Nutzen Sie diese Seite als kurze operative Übersicht für die häufigsten Aufgaben in Genkō.

---

## Checkliste für den ersten Tag

1. Kernleistungen anlegen
2. Mindestens einen Anbieter hinzufügen
3. Anbieter-Verfügbarkeit festlegen
4. Den ersten Patienten anlegen
5. Den ersten Termin buchen
6. Das Patientenportal aktivieren, wenn Self-Service gewünscht ist
7. Das Team einladen

---

## Wo häufige Aufgaben erledigt werden

| Aufgabe | Ort |
|--------|-----|
| Patienten hinzufügen | **Patients** |
| Termin buchen | **Appointments → New Appointment** |
| Anbieterzeiten festlegen | **Providers → Edit Schedule** |
| Leistungen hinzufügen oder ändern | **Settings → Services** |
| Mitarbeitende einladen | **Settings → Members** |
| Portalbuchung aktivieren | **Settings → Portal** |
| Google Calendar verbinden | **Settings → Integrations** |
| MCP-API-Schlüssel erstellen | **Settings → Integrations** |
| Plan oder Zahlungsmethode ändern | **Settings → Billing** |

---

## Terminstatus

| Status | Bedeutung |
|--------|-----------|
| Scheduled | Gebucht und aktiv |
| Completed | Besuch abgeschlossen |
| Cancelled | Buchung storniert und Zeitfenster freigegeben |
| No-show | Patient ist nicht erschienen |

---

## Rollenübersicht

| Rolle | Zugriffsübersicht |
|------|-------------------|
| Owner | Volle Kontrolle einschließlich Abrechnung und Eigentümer-Aktionen |
| Admin | Breiter operativer Zugriff einschließlich Einstellungen und Abrechnung |
| Provider | Verwaltet Termine und sieht Patientenakten |
| Staff | Unterstützt Planung und Abläufe ohne Kontrolle über Einstellungen |

## MCP-Schnellstart

1. Gehen Sie zu **Settings → Integrations**
2. Erstellen Sie einen MCP-Schlüssel
3. Kopieren Sie ihn einmalig
4. Nutzen Sie ihn als `Authorization: Bearer genko_...`
5. Richten Sie Ihren Client auf `https://www.getgenko.com/api/mcp` aus
