## まず読むページ

1. [はじめに](./01-はじめに.md) でワークスペースの初期設定を確認します。
2. [スケジュールと予約](./06-スケジュール.md) で中核となる予約フローを把握します。
3. サービスと空き状況の準備ができたら [患者ポータルと連携](./07-コミュニケーション.md) を有効にします。
4. MCP キー、AI アシスタント、各種連携は [設定、AI、API](./09-設定.md) を参照します。
