# クイックリファレンス

このページは、Genkō で最もよく使う操作を短く確認するための運用チートシートです。

---

## 初日のチェックリスト

1. 主要サービスを追加する
2. 少なくとも 1 人のプロバイダーを追加する
3. プロバイダーの空き時間を設定する
4. 最初の患者を追加する
5. 最初の予約を入れる
6. セルフ予約が必要なら患者ポータルを有効にする
7. チームを招待する

---

## よくある作業を行う場所

| 作業 | 場所 |
|------|------|
| 患者を追加する | **Patients** |
| 予約を作成する | **Appointments → New Appointment** |
| プロバイダーの勤務時間を設定する | **Providers → Edit Schedule** |
| サービスを追加・変更する | **Settings → Services** |
| スタッフを招待する | **Settings → Members** |
| ポータル予約を有効にする | **Settings → Portal** |
| Google Calendar を接続する | **Settings → Integrations** |
| MCP API キーを作成する | **Settings → Integrations** |
| プランや支払い方法を変更する | **Settings → Billing** |

---

## 予約ステータス

| ステータス | 意味 |
|------------|------|
| Scheduled | 予約済みで有効 |
| Completed | 来院が終了 |
| Cancelled | 予約がキャンセルされ枠が解放された |
| No-show | 患者が来院しなかった |

---

## ロール概要

| ロール | アクセス概要 |
|--------|--------------|
| Owner | 請求や所有権管理を含む完全な管理権限 |
| Admin | 設定や請求を含む広範な運用権限 |
| Provider | 予約管理と患者記録閲覧を担当 |
| Staff | 設定権限なしで予約と運用を支援 |

---

## プラン別の主な機能

| 機能 | 利用可能なプラン |
|------|------------------|
| Google Calendar 同期 | Solo 以上 |
| 分析 | Group 以上 |
| MCP API | Group 以上 |
| ダッシュボード AI アシスタント | Practice 以上 |
| 高度なスケジュールルール | Practice 以上 |

---

## MCP クイックスタート

1. **Settings → Integrations** に進む
2. MCP キーを作成する
3. その場で 1 回だけコピーする
4. `Authorization: Bearer genko_...` として使う
5. クライアントの接続先を `https://www.getgenko.com/api/mcp` に設定する
